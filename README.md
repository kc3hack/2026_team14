## 背景・課題・解決されること
私たちは旅行について「ある場所に行った」という事実を「コレクション」する感覚が楽しいと考えている．
しかし，その「コレクション」を実際のものとして保存することは難しい．
そこでデータとしてそのコレクションを保存できるアプリを開発したいと考えた．
確かに既存アプリに似たようなことができるアプリがあるのだが，コレクション要素よりも集金のためのバトル要素が強く肝心の旅行を楽しみづらかったり，そもそも旅行を主眼に置いたアプリではなかったりと私たちの要求を満たせるようなものではなかった．そのため旅行をコレクションとして楽しむ以外の要素を極力排除したアプリを開発した．
